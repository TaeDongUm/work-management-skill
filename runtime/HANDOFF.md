## 다음 세션의 확인 순서
1. 제공 지침과 WORKFLOW를 확인한다.
2. WORKLOG의 현재 상태와 여기서 참조한 요구·설계·검증 항목을 읽는다.
3. 실제 파일·변경 상태와 인계 기록이 일치하는지 확인한다.
   재접속 시 기존 장기 작업·프로세스가 살아 있는지 확인하고 중복 실행하지 않는다. 연결 끊김과 작업 중단을 동일시하지 않는다.
4. 불일치가 있으면 사실을 확인해 기록을 정정한다.
5. 기존 작업을 불필요하게 다시 만들지 않고 다음 중요한 작업을 진행한다.

인계 기록은 현재 상태의 요약이지 정답 보증이 아니다. 인증 정보·비밀값은 포함하지 않는다.


## 인계를 고려할 징후
- 작업을 중단하거나 세션을 전환해야 할 때.
- 합의된 제약을 반복해서 놓치거나 해결된 작업을 다시 시작할 때.
- 대화가 길어져 현재 상태와 다음 작업이 불명확할 때.
먼저 현재 상태를 짧게 정리해 복구 가능한지 판단한다. 고정 주기로 새 세션을 강제하지 않는다.
전환을 결정하면 기존 세션에서 인계를 작성하고 새 세션은 실제 파일과 대조한 뒤 이어간다.
