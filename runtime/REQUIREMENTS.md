## 미확정 처리와 역제안
| 질문 ID | 남은 쟁점·출처 | 결과·구조에 미치는 영향 | 구체적 재질문 | 제안·대안·대가 | 실제 답변 | 상태·다음 행동 |
|---|---|---|---|---|---|---|
상태: 질문 대기 / 역제안 대기 / 합의됨 / 개발자 결정 / 임시 가정 / 차단 / 보류.
확정된 사실을 반복해서 질문하지 않는다. 핵심 업무 결정은 짧은 재질문 후 역제안한다.
침묵·애매한 동의를 모든 세부 조건의 승인으로 해석하지 않는다. 필요한 경우 제안 범위를 다시 좁혀 확인한다.
담당자 합의가 원문 필수 조건과 충돌하면 덮어쓰지 말고 충돌로 기록한다.
대답을 못 받았다는 이유로 필수 요구를 삭제하지 않는다. 영향받는 구현만 보류하고 독립적인 작업은 진행한다.
