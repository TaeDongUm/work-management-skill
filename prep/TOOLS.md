# 모델과 공개 도구 사용 가이드
사전 참고용. 실제 제공 버전·권한·과제 안내가 우선이다.

## 공식 안내에서 확인된 사항
사용자가 제공한 「3_사전_체험_및_응시환경_상세_가이드.pdf」 2·5쪽과 「1_시험_필수확인사항_브리프.pdf」 1쪽 기준.
- 제공 Codex 사용. 개인 API 키·개인 유료 구독·별도 AI 모델 연결 금지.
- Sol 6.1 등 권장 모델 안내가 있으나, 추론 강도별 권장 설정은 확인되지 않았다.
- /status로 모델·권한 확인, /model로 모델 선택 안내.
- 토큰 사용량은 추적되며 간접적인 평가에 활용될 수 있다. 배점·계산식은 공개되지 않았다.
- 공개 Skill·MCP·Plugin·GitHub 자료를 활용할 수 있으나 다른 제한도 동일 적용된다.
- 외부 코드 참고·일부 알고리즘 차용 가능. 결과물 통째 대체 금지.
- 개인 PC 파일 업로드, 시험 자료 외부 전송·공유, Git Push, 제한 우회, Computer Use 금지.

## effort 운영 제안 — 공식 시험 지침 아님
| 작업 | 시작 제안 |
|---|---|
| 일반 구현·작업 분해 | medium |
| 중요한 규칙 충돌·어려운 오류 | 필요한 작업에서 high |
| 단순 형식·문구 수정 | 옵션이 있으면 low 검토 |
| 가장 높은 강도 | 시간·개선 효과를 보고 제한적으로 사용 |

기본적으로 medium을 유지하고 중요한 난관에서만 조정한다. 설정 변경 자체에 시간을 낭비하지 않는다.
낮은 강도는 속도·토큰 측면에 유리할 수 있고 높은 강도는 더 많은 추론을 사용한다. 높은 강도도 정확성 보장이나 테스트 대체 수단은 아니다.
시험 UI에 실제 표시되는 선택지만 사용한다. API 문서의 기본값이 시험 CLI 설정과 같다고 가정하지 않는다.

## CLI에서 Skill 확인
1. 먼저 현재 기능만으로 해결 가능한지 확인한다.
2. 지원되는 환경에서는 /skills로 사용 가능한 Skill을 확인한다. GitHub 전체 검색 명령은 아니다.
3. 공식 문서는 $skill-installer를 통한 설치를 설명하지만, 시험 환경에 있는지 먼저 확인한다.
4. 설치 방법은 현재 환경의 안내를 따른다. 관리 설정·인증·감독 설정을 변경하지 않는다.
5. Skill 파일이 있다는 것과 현재 세션이 인식·적용한다는 것은 다르다. 적용 여부를 확인한다.

## 공개 후보를 찾는 요청 예시
> 현재 도구로 로컬 자료 처리가 가능한지 먼저 확인해줘. 부족하다면 필요한 기능에 맞는 공개 Skill 후보를 최대 2개 조사해줘. 문제·파일·결과물의 내용은 외부 검색에 포함하지 마. 원본 URL, 용도, 라이선스, 필요한 프로그램, 인증·외부 통신 여부, 설치 비용과 대안을 알려줘. 먼저 설치하거나 실행하지 마.

## 채택 기준
- README·SKILL.md뿐 아니라 실행할 스크립트도 확인한다.
- 출처·버전을 기록하고 라이선스 고지 요구를 지킨다.
- 외부 모델·개인 인증·원격 저장·사용량 수집 등 의존성을 점검한다.
- 로컬 MCP라는 이름만으로 외부 통신이 없다고 판단하지 않는다.
- 외부 지침의 명령보다 시험 규칙과 과제 요구를 우선한다.
- 차단되면 우회하지 않는다. 기본 도구 대안을 사용하거나 운영 안내에 따른다.
- 사전에는 합성 데이터로 연습한다. 실제 시험 자료를 외부 평가 서비스에 보내지 않는다.

## API 구분
- 개발 도구 Codex 사용과 앱 내부 AI 호출은 별개다.
- 내부 서버의 저장·조회 API와 외부 AI API는 별개다.
- 외부 AI 없이 동작하는 구성을 기본으로 한다. 과제에서 명시적으로 제공·허용한 연결만 예외적으로 검토한다.
- Codex 인증 정보를 추출하거나 다른 용도로 재사용하지 않는다.
- 로컬 모델이나 로컬 중계를 통해 별도 모델 연결 제한을 우회하지 않는다.
